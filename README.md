# ⚡ Puzzle Energy Box

Um puzzle interativo desenvolvido para a campanha de RPG **Ordem Paranormal — Vendeta Oculta**, especificamente para a **Missão 0 — Fumaça Púrpura**.

O jogador precisa identificar e posicionar corretamente os fusíveis na caixa de energia para ativar diferentes sistemas do trem.

## 🎮 Jogar

👉 **[Acessar o Puzzle Energy Box](https://ivaldomugi.github.io/PuzzleEnergyBox/)**

## 🧩 Sobre o projeto

O Puzzle Energy Box foi desenvolvido como uma ferramenta interativa para utilização durante uma sessão de RPG na **Missão 0 — Fumaça Púrpura**.

A ideia é transformar um puzzle que poderia ser resolvido apenas com papel e anotações em uma experiência visual e interativa para os jogadores.

O jogador pode:

- 🔌 Arrastar fusíveis para a caixa de energia
- 🧩 Resolver diferentes combinações de fusíveis
- 🚪 Ativar sistemas e portas do trem
- ⚡ Identificar visualmente as combinações ativas
- 🔊 Receber feedback sonoro ao ativar uma nova combinação

## ⚙️ Combinações

As combinações disponíveis no puzzle representam diferentes sistemas do trem:

| Fusíveis | Sistema ativado |
|---|---|
| 🔴 Vermelho + 🟢 Verde | Todas as portas abertas |
| 🔴 Vermelho + 🟢 Verde + 🟡 Amarelo 1 | Porta da cabine aberta |
| 🔴 Vermelho + 🟡 Amarelo 1 | Portas da tripulação e depósito abertas |
| 🔴 Vermelho + 🟡 Amarelo 2 | Portas dos passageiros abertas |
| 🌸 Rosa + 🟣 Roxo | Elétrica do trem funcionando |

> Algumas combinações podem ser ativadas simultaneamente.
